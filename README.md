# Digital Clock Project

The **Digital Clock** project is a React-based application that displays the current date and time. The goal of this project was to understand and work with the JavaScript **Date API** for real-time updates of time and date. It also includes additional features like a toggle between 12-hour and 24-hour formats.

## Project Overview

- **Goal**: The main goal of this project was to get hands-on experience with the JavaScript `Date` API and to understand how to work with real-time data.

- **Technologies Used**:
  - React.js
  - JavaScript `Date` API
  - Tailwind CSS for styling

## Features

- **Real-time Clock**: The clock updates every second to display the current time.
- **Dynamic Date**: The current date is displayed in a readable format.
- **Responsive Design**: The project is designed to be fully responsive and works well on mobile and desktop devices.

## How to Run the Project Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/sk-adi/DigitalClock.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DigitalClock
   ```

3. Install the necessary dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Learning Goals

- Understand how to work with the **JavaScript Date API**.
- Learn how to display dynamic data in a React application.
- Practice using **React hooks** (`useState`, `useEffect`).
- Experiment with **real-time updates** and **intervals**.
- Improve CSS skills using **Tailwind CSS** for responsive design.
